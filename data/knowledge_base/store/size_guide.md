## 3. シーツの仕様（フラット / ボックス / ベッドスカート）

| 仕様 | 日本語名 | 特徴 |
|---|---|---|
| 床单款 | フラットシーツ | 四角い布を敷くタイプ。マットレスの下に挟んで使う |
| 床笠款 | ボックスシーツ | 袋状でマットレス全体を包む。ズレにくい |
| 床裙款 | ベッドスカート | マットレスを包み、裾にフリルがあるタイプ |
| 床盖款 | カバーレット | ベッド全体を覆う一枚布。ベッドカバーとしても使える |

- **ズレが気になる方**にはボックスシーツ（床笠款）がおすすめです。
- ベッドの厚さが**25cm以上**の場合は、ボックスシーツのサイズに余裕が必要です。

| 表示 | 用途 | 重さの目安 |

| 夏被（夏用） | 6〜9月 | 1〜2斤（約0.5〜1kg） |
| 春秋被（中厚） | 4〜5月・10〜11月 | 3〜4斤（約1.5〜2kg） |

| 四季被 | 通年 | 3〜5斤（約1.5〜2.5kg） |

- 「斤」は中国の重量単位で、**1斤＝約500g**です。
- 商品名の「150*200cm 4斤」は「150×200cm、中綿約2kg」の意味です。
- 寒冷地（北海道・東北）の冬は、冬被または厚手の羊毛・羽毛被をおすすめします。

## 5. 4点セット・3点セットの内容

- **4点セット（四件套）**：掛け布団カバー×1、シーツ×1、枕カバー×2
- **3点セット（三件套）**：掛け布団カバー×1、シーツ×1、枕カバー×1

- 「A類」「B類」は中国の国家基準（A類は婴幼儿向けの厳しい基準）です。
  A類の商品は、お子様や敏感肌の方にも安心してお使いいただけます。

## 6. サイズ選びでよくあるお問い合わせ

**Q. 1.5mのベッドですが、150×200cmの掛け布団カバーで合いますか？**
A. 問題なくご使用いただけます。掛け布団カバーは布団本体と同じサイズで問題ありません。

**Q. 手持ちの掛け布団が190×210cmです。どのカバーを選べばいいですか？**
A. 1.8m向けの200×230cmですと大きすぎる場合があります。
掛け布団の実寸を確認のうえ、同じサイズのカバーをお選びください。

**Q. ボックスシーツがきついです。**
A. 中国製は日本の規格より小さめに作られている場合があります。
マットレスの厚さと実寸をご確認のうえ、ワンサイズ上をご検討ください。

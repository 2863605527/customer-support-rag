# ご注文後の変更・キャンセルについて

越境発送のため、ご注文が中国の倉庫へ送られると変更・キャンセルができなくなります。
お手続きは**できるだけ早く**ご連絡ください。

## 1. 変更・キャンセルができるタイミング

| タイミング | 変更・キャンセル |
|---|---|
| ご注文から**1時間以内**（発送準備前） | キャンセル・内容変更ともに可能 |
| 発送準備中（ご注文の1時間後〜発送まで） | **キャンセル不可**。内容変更は在庫があれば個別対応 |
| 発送後 | 変更・キャンセル不可。到着後に**返品**でのご対応 |

- 「発送準備の開始」はお客様からは判断できないため、
  **変更したい場合はすぐに**カスタマーサポートへご連絡ください。
- 在庫・倉庫の稼働状況により、上記より早く締め切られる場合があります。

## 2. キャンセルの手続き

1. カスタマーサポートへ**注文番号**をお知らせください。
2. 当店で発送準備の状況を確認します（通常数時間以内）。
3. 準備前であれば、キャンセルを承ります。
4. 返金は**5営業日以内**に処理します。クレジットカードの場合は
   反映までさらに**7〜14日**かかることがあります。

- 発送準備に入った後は、キャンセルをお受けできません。
  お手数ですが、商品到着後に返品の手続きをお願いします。

## 3. 内容の変更（サイズ・色・数量）

- 発送準備前であれば、**在庫がある範囲で**変更を承ります。
- サイズ変更で**価格が変わる場合**は、差額のご請求または返金が発生します。
  （一度キャンセルして再注文いただく形になる場合があります）
- 数量の追加は、別注文として承る形になります。
  同梱をご希望の場合は、発送前にお知らせください（できる限り対応します）。

## 4. お届け先住所の変更

- **発送前**：カスタマーサポートへご連絡いただければ変更できます。
- **発送後**：配送業者への**転送依頼**となり、追加料金と日数がかかる場合があります。
  配送業者へ直接ご連絡ください。
- 住所の入力間違いによる**再発送**は、往復の送料をご負担いただきます。

## 5. 支払い方法の変更

- TikTok Shop の仕様上、**ご注文後の支払い方法の変更はできません**。
- 変更をご希望の場合は、**一度キャンセル**していただき、再注文をお願いします。
  （キャンセル可能なタイミングに限ります）
- 当店から個別にお支払いを求めるご連絡は一切いたしません。
  そのような連絡があった場合は、詐欺の可能性がありますのでご注意ください。

## 6. 注文番号について

- 注文番号は、TikTok Shop の**ご注文履歴**からご確認いただけます。
- お問い合わせの際は、注文番号をお知らせいただくと対応が早くなります。
- 注文番号が分からない場合は、**ご注文時の登録メールアドレス**をお知らせください。

## 7. 領収書・請求書

- 領収書はご注文履歴からダウンロードいただけます。
- 宛名の変更が必要な場合は、カスタマーサポートへご連絡ください。
- **適格請求書（インボイス制度）には対応していません**。
  当店は中国からの越境販売のため、日本国内の適格請求書発行事業者ではありません。

## 8. よくあるご質問

**Q. 注文直後に間違いに気づきました。まだ間に合いますか？**
A. ご注文から1時間以内であれば、キャンセルできる可能性が高いです。
すぐにカスタマーサポートへご連絡ください。

**Q. 昨日注文した商品をキャンセルできますか？**
A. すでに発送準備に入っている可能性が高く、キャンセルはお受けできません。
到着後の返品（商品到着後30日以内）でのご対応となります。

**Q. 注文した商品と違うものが届きました。**
A. 誤配送ですので、当店負担で交換いたします。
注文番号と、届いた商品・お届けしたかった商品の写真をお送りください。

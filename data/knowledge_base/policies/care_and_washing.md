# お手入れ・洗濯ガイド（素材別）

寝具は毎日肌に触れるものなので、お手入れ方法のお問い合わせが多く寄せられます。
素材ごとの洗い方と、よくある失敗（縮み・色落ち・毛羽立ち）の避け方をまとめています。

## 1. 洗濯表示の読み方

商品ページの洗濯表示は、日本工業規格（JIS L 0001）に準じた記号で表示しています。

| 表示 | 意味 |
|---|---|
| 洗濯機マーク（数値なし） | 洗濯機で洗えます |
| 洗濯機マーク（30 / 40） | 液温30℃ / 40℃以下で洗濯 |
| 手洗いマーク | 手洗いのみ（洗濯機不可） |
| バケツに斜線 | 水洗い不可（ドライクリーニングのみ） |
| 三角マーク | 酸素系漂白剤のみ使用可（塩素系は不可） |
| 三角に斜線 | 漂白剤は使用不可 |
| タンブラー（乾燥機）に斜線 | 乾燥機は使用不可 |
| アイロン（1〜2個） | 低温（80〜120℃）でアイロン可 |
| 丸マーク | ドライクリーニング可 |

- 表示がない商品は、**陰干し**と**中性洗剤での手洗い**をおすすめします。

## 2. 素材別の洗い方

### 綿100%（コットン）

- 洗濯機で洗えます。液温40℃以下、**弱コース**でお願いします。
- 初回は**単独で洗ってください**。濃色は最初の3回ほど色が出ます。
- 綿は洗濯後に**縦方向で2〜3%程度縮む**ことがあります。これは品質不良ではありません。
- 乾燥機の使用は避けてください。高温で縮みが大きくなります。

### 二重ガーゼ

- 洗濯機で洗えます。**洗濯ネットに入れ**、弱コースで洗ってください。
- 柔軟剤は控えめに。使いすぎると**吸水性が落ちます**（ガーゼの良さが失われます）。
- 乾くにつれて生地が少し縮み、ふんわりとした風合いが出ます。

### 化学繊維（ポリエステル・マイクロファイバー）

- 洗濯機で洗えます。低温・短時間で十分です。
- 乾きが早く、縮みにくい素材です。
- 冬場は静電気が起きやすいため、乾燥しすぎを避け、柔軟剤を使うと軽減します。

### フランネル・珊瑚絨（コーラルフリース）

- 洗濯機で洗えますが、**他の衣類と分けて**洗ってください。毛羽が付着します。
- 高温で洗うと毛羽立ちが早まるため、**30℃以下**をおすすめします。
- 乾燥機を使う場合は低温で。高温だと毛が寝て、手ざわりが硬くなります。

### ウール（羊毛）

- **手洗い、またはドライクリーニング**をおすすめします。
- 手洗いの場合：30℃以下のぬるま湯に中性洗剤を溶かし、**押し洗い**をしてください。
  もみ洗い・ねじり絞りは縮み（フェルト化）の原因になります。
- 脱水は洗濯機を使わず、タオルで挟んで水分を吸わせ、**平干し**してください。

### 羽毛（ダウン・フェザー）

- 手洗い、または洗濯機の**羽毛専用コース**で洗えます。中性洗剤をお使いください。
- **完全に乾かすことが最も重要です**。生乾きは嫌なにおいとカビの原因になります。
- 乾燥機を使う場合は低温で、**乾燥ボールやテニスボール**を一緒に入れると
  羽毛がほぐれてふくらみが戻ります。
- 1シーズンに1回程度のお手入れで十分です。

### 麻・竹繊維（リネン・竹）

- 洗濯機の**弱コース**で洗えます。
- 麻は洗うほど柔らかくなりますが、強い脱水はシワの原因になります。
- 乾きが早いので、陰干しで十分です。

## 4. 洗濯でよくあるトラブル

**Q. 洗ったら縮んでしまいました。**
A. 綿・ガーゼは水を含むと繊維が縮み、乾燥の過程で2〜3%ほど縮むことがあります。
濡れた状態で軽く引っ張りながら形を整えて干すと、縮みを抑えられます。

**Q. 色落ちして他の洗濯物に色が移りました。**
A. 濃色（ネイビー・ブラック・赤系）は初回に色が出やすいため、
最初の2〜3回は単独で洗ってください。

**Q. 毛玉ができました。**
A. 摩擦で発生します。洗濯ネットの使用と、洗濯物を入れすぎないことが有効です。
既にできた毛玉は、毛玉取り器で除去してください。

**Q. 柔軟剤を使ってもいいですか？**
A. 使えます。ただし**タオル・ガーゼ類は吸水性が落ちる**ため、控えめにしてください。
羽毛製品には柔軟剤を使わないでください（羽毛の油分が落ち、ふくらみが悪くなります）。

**Q. 漂白剤は使えますか？**
A. 酸素系漂白剤は多くの商品で使えますが、**塩素系漂白剤は変色・生地の傷みの原因**に
なりますので使用しないでください。

## 5. 干し方と収納

- 基本は**陰干し**です。直射日光は色あせの原因になります。
- 風通しのよい場所で、できるだけ**平らに、または幅を広げて**干してください。
- 押し入れに収納する前に、**必ず完全に乾かしてください**。湿ったまま収納すると
  カビとにおいの原因になります。
- 羽毛製品の長期収納に**圧縮袋は不向き**です。圧縮すると羽毛が潰れ、
  次シーズンにふくらみが戻りにくくなります。
- 防虫剤は他の衣類と同じ場所に置き、商品に直接触れないようにしてください。

## 6. ダニ・ハウスダスト対策

- ダニは**温度60℃以上、または湿度50%以下**で活動が弱まります。
- 週に1回、布団を**乾燥機で20分ほど**まわすと、ダニの死滅と湿気の除去に効果的です。
- 天日干しは湿気を飛ばす効果はありますが、ダニを死滅させるには温度が足りません。
  天日干しのあとに**叩いて落とす**のが有効です。
- カバー類は週1回の洗濯で、エサとなる皮脂・汗を落としてください。
